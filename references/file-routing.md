# 文件归档规则

| 内容 | 目标目录 | 常见文件 |
|---|---|---|
| 开题书、定题书、开题方案 | `01 开题书` | PPTX、PDF、PNG、JPG |
| 学习手册、项目说明 | `02 学生项目手册` | HTML、PDF、DOCX |
| 结构、外形、激光切割、接线和原理图 | `03 项目图纸` | STL、3MF、STEP、SCAD、DXF、LCPX、SVG、PNG |
| 程序、配置、依赖和完整代码文件夹 | `04 项目代码` | MP、PY、INO、C、H、JSON、BIN、文件夹 |
| 已实现功能的照片或截图 | `05 项目关键性图片/功能实现图（4张）` | JPG、PNG |
| 实验操作、对照和数据照片 | `05 项目关键性图片/实验关键图片（6张）` | JPG、PNG |
| 完整装置和整体外观 | `05 项目关键性图片/项目原型图（1-2张）` | JPG、PNG |
| 学生制作、接线、组装和调试过程 | `05 项目关键性图片/制作过程关键图（5张以上）` | JPG、PNG |
| 灵感、背景和暂不属于以上分类的参考图 | `05 项目关键性图片/其他参考资料` | JPG、PNG、PDF |
| 开题或成果答辩演示、讲稿和申报文件 | `06 答辩ppt` | HTML、JSON、MD、PPTX、PDF |
| 项目演示和讲解视频 | `07 项目视频` | MP4、MOV |
| 最终签字交接单 | `08 项目装置交接单` | PDF、JPG、PNG |
| 学生论文和研究报告 | `09 可选-学生论文` | DOCX、PDF |
| 每日文字日志、视频提纲和日志视频 | `10 研究日志` | MD、JSON、MP4 |
| 无法确认内容或归属 | `99 待确认` | 任意 |

## 命名

- 保留能说明内容的原名，删除无意义的“最终最终”“新建文件”等字样。
- 需要标记来源时，在扩展名前增加 `-老师提供版`、`-学生制作版` 或 `-AI生成版`。
- 同名不同内容使用 `-v2`、`-v3` 递增，不覆盖。
- 不清楚的文件保持原名并进入 `99 待确认`。
