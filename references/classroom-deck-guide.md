# 课堂演示生成器

## 目标

让学生负责理解和讲述项目。AI先根据开题书和学生表达准备三张图，再填写受控数据；固定模板负责生成离线HTML，并在浏览器中导出每页为高清图片、讲稿写入备注的PPTX。

不要让学生写HTML、选字体、调整版式或处理导出技术问题。

## 固定输出

开题答辩保存到：

```text
06 答辩ppt/D3开题答辩/
├─ 开题答辩.html
├─ 演示内容.json
├─ 逐页讲稿.md
└─ assets/
```

成果答辩保存到：

```text
06 答辩ppt/D7成果答辩/
├─ 成果答辩.html
├─ 演示内容.json
├─ 逐页讲稿.md
└─ assets/
```

学生打开HTML上台演讲。点击页面右上角“导出申报PPTX”，浏览器会下载与HTML视觉一致的PPTX。导出后把PPTX复制回同一答辩目录，不移动或覆盖旧版本。

## 生成顺序

1. 确认当前学生档案和答辩阶段。
2. 开题阶段确认老师已经检查复述和开题书。
3. 读取 `references/d3-visual-preparation.md`，依次准备概念图、流程图和硬件框图；不要跳过概念图质量检查。
4. 查看候选图片并让学生确认每张图片是什么；不要只凭文件名猜。
5. 根据 `references/classroom-deck-schema.json` 形成演示JSON；为D3图片填写 `role`、`origin`、`review_status` 和 `description`，为每页填写 `source_refs`。
6. 先运行校验：

```bash
node scripts/validate-classroom-deck.mjs --input "演示内容.json"
```

7. 校验通过后运行构建：

```bash
node scripts/build-classroom-deck.mjs --input "演示内容.json" --output "目标答辩目录"
```

8. 打开生成的HTML，逐页检查图片、文字和讲稿。
9. 让学生连续讲一遍；修改内容时只改演示JSON并重新构建，不直接改模板CSS或JS。
10. 点击“导出申报PPTX”，确认下载文件能够打开、页数正确、备注中有讲稿。

## 低自由度规则

- D3必须严格使用 `D3-01` 至 `D3-06` 六页。
- D7必须严格使用 `D7-01` 至 `D7-10` 十页。
- 不允许新增页面ID、HTML标签、CSS、JavaScript或自定义主题。
- 不允许从网络临时下载模板、字体、图标或其他Skill。
- 图片使用本地文件；构建脚本会复制到输出目录。
- 模板使用Windows与macOS常见中文字体，不依赖在线字体。
- 每页只讲一个主要意思；放不下时先删减，不缩小到难以投屏阅读。

## D3固定页序

| ID | 任务 | 必需素材 |
|---|---|---|
| `D3-01` | 项目名称与一句话目标 | 清晰场景图，作为半透明背景 |
| `D3-02` | 问题由来与使用场景 | 开题书内容依据；相关场景图建议提供 |
| `D3-03` | 装置概念图 | 通过质量检查的AI概念图；不合格时按规则回退 |
| `D3-04` | 工作流程图 | 保留完整项目逻辑的流程图 |
| `D3-05` | 硬件框图 | 含ESP32默认主控和按需AI分支的框图 |
| `D3-06` | 原始开题书 | 原始开题书整页图片 |

## D7固定页序

| ID | 任务 | 必需素材 |
|---|---|---|
| `D7-01` | 项目名称与一句话成果 | 原型图可选 |
| `D7-02` | 问题由来与使用场景 | 真实场景或调研图可选 |
| `D7-03` | 调研证据与现有办法 | 真实证据可选 |
| `D7-04` | 项目目标与核心功能 | 无 |
| `D7-05` | 整体方案与技术原理 | 三图中最能说明整体的一张 |
| `D7-06` | 实际制作与关键选择 | 制作过程图 |
| `D7-07` | 原型成品与演示 | 原型成品图 |
| `D7-08` | 实验设计 | 实验过程图可选 |
| `D7-09` | 实验结果与迭代 | 真实记录、数据或对比图 |
| `D7-10` | 结论、创新、限制与未来改进 | 无 |

## 无Node环境的降级

优先运行构建脚本。若宿主不能运行Node.js，但能够复制与编辑本地文件：

1. 复制 `assets/classroom-deck/template.html` 和整个 `assets/classroom-deck/vendor/`。
2. 只把模板里的 `__DECK_DATA__` 替换为校验后的JSON。
3. 保持模板其余内容逐字不变。

如果宿主既不能运行脚本，也不能安全复制模板与素材，停止并请老师换到可用电脑；不要让模型临时自由编写另一套HTML。

## 验收

- HTML离线打开，16:9显示，左右键、空格、Home、End和全屏可用。
- `N`键能查看当前页讲稿，讲稿不出现在观众画面中。
- 封面场景图清晰并以半透明背景呈现。
- 概念图是实体作品使用场景，不是流程框图或硬件框图。
- 流程图保留项目的重要模式、判断和反馈，没有为追求简单删掉关键逻辑。
- 硬件框图包含传感器、执行器、电源、通信和控制模块；AI分支只在实际使用时出现。
- 第六页完整显示原始开题书。
- 导出的PPTX页数与HTML一致，每页是高清图片。
- PPTX备注中有对应讲稿。
- D3固定六页，没有验证计划页、制作过程、原型成品或虚构实验结果。
- D7只展示真实存在的制作、原型和实验材料。
