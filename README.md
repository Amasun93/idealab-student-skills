# ideaLab 学生端 Skills

面向 ideaLab 竞赛营学生的 WorkBuddy Skills。学生只需下载一次，即可获得项目归档和研究日志两项能力。

## 包含内容

- `student-project-archive`：通过口述建立个人项目档案，整理老师提供、学生制作和 AI 生成的材料。
- `student-research-log`：通过逐题口述完成每日研究日志，并生成 60—90 秒视频日志提纲。

## 学生档案结构

学生端沿用教师端随堂调试的 `01—09` 目录，并新增：

- `10 研究日志`
- `99 待确认`

根目录格式：`随堂调试-学生姓名-项目名称`。

## 使用顺序

1. 在 GitHub 页面点击 `Code` → `Download ZIP`。
2. 解压后安装两个 Skill 文件夹。
3. 第一次先使用 `student-project-archive`，口述姓名、项目和年级，建立个人档案。
4. 每天课程结束后使用 `student-research-log`，完成复盘和视频提纲。
5. 不能确定归属的材料先放入 `99 待确认`，交给随堂老师检查。

这两个 Skill 默认只复制材料，不删除原文件、不覆盖同名文件，并通过内容哈希避免重复归档。
