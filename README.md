# ideaLab 学生课堂项目助手

这是一个在 ideaLab 课堂中帮助学生理解、讲解并管理个人项目的聚合型 Skill。学生只需要记住 ideaLab Student；开题、最终答辩、归档和日志等专项能力由它自动识别和调用。

它帮助学生把上课过程中收到、制作和生成的材料整理进同一个项目档案，并通过口述完成每天的研究日志。课程结束后，随堂老师可以直接收取学生的完整项目文件夹，继续合并和整理正式交付材料。

当前包含开题复述训练、开题答辩训练、成果答辩训练、项目归档和研究日志。所有能力继续使用同一套项目档案。

## 什么时候使用

- 学生第一次开始个人项目，需要建立自己的项目档案。
- 学生完成老师讲解后，需要用自己的话复述项目并找出没有讲清楚的部分。
- 开题阶段需要准备三张图、开题演示和约四分钟讲解。
- 每次课结束后，需要口述当天的研究日志和视频日志提纲。
- 项目制作过程中，需要把图纸、代码、照片和 AI 生成材料放入同一个档案。
- 结课前需要根据真实成果准备最终答辩，不编造没有完成的效果。

它不负责星核板接线、Mind+ 代码或三维外壳开发；硬件项目使用 `starcore-project-maker` 或课堂批准的学生版星核板 Skill。它也不负责老师一次整理全班散乱材料；教师批量归档使用 `suitangtiaoshi-skill`。

## 在哪里使用

- 安装在学生上课使用的 WorkBuddy、Codex 或其他支持 Skill 的 AI 工具中。
- AI 需要能够访问当前学生自己的项目文件夹，才能保存档案、日志、HTML 和 PPTX。
- 建议每名学生始终在同一个 `随堂调试-{姓名}-{项目名称}` 文件夹中继续工作。
- 不应让学生访问其他学生的项目卡、档案或教师内部备注。

## 怎么使用

安装整个 `idealab-student-skills` 文件夹，保持 `SKILL.md`、`references`、`assets` 和 `scripts` 在一起。学生不需要记忆固定指令，可以直接说：

> 我第一次做这个项目，帮我建立项目档案。

> 我想先用自己的话讲一遍项目，你听完再问我没讲清楚的地方。

> 老师已经检查过我的复述和开题书了，帮我先准备三张图，再做开题答辩。

> 帮我记录今天做了什么，一次问我一个问题。

> 我要准备最后的成果答辩，只使用我文件夹里真正做出来的材料。

AI 会先寻找现有的 `学生项目档案.json`。找到后继续使用原档案，不重复询问姓名，也不另建一套目录。涉及写入、复制或改名时，会先说明操作并等待确认。

## 当前能力

### 开题复述训练

- 学生看完老师的视频或逐字稿后，先用自己的话连续讲一遍。
- AI一次只追问一个关键缺口，不把项目卡直接变成背诵答案。
- 结束时生成给老师查看的评估卡，包含练习等级、对话总结、待关注内容和是否建议正式复述。
- AI评价只用于练习，正式检查和课堂加分由老师决定。

### 开题答辩训练

- 学生自然表达“我要做开题答辩PPT”即可；状态不清楚时，AI再询问老师是否检查过复述和开题书。
- 老师确认后，按约四分钟讲解加一分钟提问准备开题PPT。
- 先根据开题书生成概念图、工作流程图和硬件框图，再编译HTML。概念图默认生成一张，不合格时只重试一次，仍不合格时回退到学生手绘图或开题书参考图。
- 一次只完成一页，先让学生说“最想让听众听懂什么”，再整理页面和讲法。
- 开题阶段固定六页：封面、问题由来、概念图、流程图、硬件框图和原始开题书，不编造制作过程与实验结果。
- 使用固定课堂演示模板自动生成离线HTML，并导出每页为高清图片、讲稿写入备注的PPTX。

### 成果答辩训练

- 最后一天由内置 `defense-presentation` 模块先盘点本地材料，再让老师或学生确认使用方案。
- 始终保持“问题—现有方案—不足—本项目功能—创新—实验”的推导链，页面数量按项目材料动态变化。
- 缺少原型、制作或实验照片时显示“待补”占位，AI示意图不能冒充真实证据。
- 默认输出离线答辩HTML、逐页参考稿、素材盘点和独立交互练习页；姓名和项目简称会进入封面与文件名。

### 内置专项 Skill

- `idealab-student-skills` 是学生唯一入口，学生无需记住其他 Skill 名称。
- `references/skill-registry.json` 记录随主 Skill 一起更新的专项模块。
- 运行 `node scripts/manage-bundled-skills.mjs check` 可以检查全部内置模块是否完整。
- 当前首个模块是 `modules/defense-presentation`；后续模块继续通过同一入口扩展。

### 项目归档

- 第一次使用时询问学生姓名、项目名称、年级和保存位置。
- 建立完整的课堂项目目录。
- 整理老师提供、学生制作和 AI 生成的文件。
- 不确定的材料进入 `99 待确认`，交给随堂老师判断。
- 只复制材料，不删除原文件，不覆盖同名文件。

### 研究日志

- 通过逐题口述，帮助学生回顾当天学到的内容、完成的任务、遇到的困难和解决方法。
- 记录 AI 提供了什么帮助，以及学生自己做了什么判断和修改。
- 保存完整研究日志、原始回答记录和 60—90 秒视频日志提纲。

## 完整项目结构

```text
随堂调试-{学生姓名}-{项目名称}/
├─ 01 开题书/
├─ 02 学生项目手册/
├─ 03 项目图纸/
├─ 04 项目代码/
├─ 05 项目关键性图片/
│  ├─ 功能实现图（4张）/
│  ├─ 实验关键图片（6张）/
│  ├─ 项目原型图（1-2张）/
│  ├─ 制作过程关键图（5张以上）/
│  └─ 其他参考资料/
├─ 06 答辩ppt/
├─ 07 项目视频/
├─ 08 项目装置交接单/
├─ 09 可选-学生论文/
├─ 10 研究日志/
└─ 99 待确认/
```

每天的研究日志保存在：

```text
10 研究日志/YYYY-MM-DD_Dn/
├─ 研究日志.md
├─ 视频日志提纲.md
└─ 回答记录.json
```

## 设计原则

- 面向以小学生为主的课堂，一次只问一个短问题，优先支持口述。
- 从学生的普通表达判断意图，不要求记忆固定指令或入口暗号。
- 所有课堂能力共用同一个学生项目档案，不建立互相分离的文件夹。
- AI帮助学生整理和复盘，但不替学生编造经历、收获或判断。
- 学生自己生成的内容、老师提供的材料和后续新增能力，都继续归入这套结构。
