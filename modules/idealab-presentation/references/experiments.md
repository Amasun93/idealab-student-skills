# 实验设计与学生采访

实验的任务是让学生理解“怎样知道装置大致解决了核心问题”。优先形成可讲清的闭环，不追求超出年龄和课堂条件的学术复杂度。

## 1. 三类验证

### 功能验证

确认输入、处理和输出能否按预期发生。例如刷卡后能否识别、识别后对应灯是否点亮。它是基础，但通常不足以单独证明项目解决了问题。

### 效率/效果验证

直接对应核心目标。将本项目方法与原有方法、现有方案或使用前状态比较，尽量保持任务、场景和参与者条件一致。

常见指标：完成时间、成功率、错误次数、需要提示次数、理解正确数、任务完成度、操作步骤或人工协助次数。

### 性能测试

说明装置在什么范围内稳定工作。常见指标：识别距离、响应时间、准确度、稳定运行次数、承重、续航、耐久、亮度、声音范围和适用环境。

先验/原理实验是条件项：当方案依赖一个未经确认的现象、材料特性或结构计算时，可在制作前验证。

## 2. 一问一答采访

不要一次抛出整张问卷。根据前一回答，每次只问一个最关键的问题：

1. “你最想证明装置的哪一个效果？”
2. “你当时具体让它做了什么任务？”
3. “你和什么方法或状态做了比较？”
4. “一共试了多少次？成功、失败分别多少次？”
5. “你记录了时间、距离、次数或其他数字吗？”
6. “失败时出现了什么现象？后来改了什么？”
7. “修改后有没有再测？结果怎样？”

如果学生说不清，提供贴合项目的2–3个可选指标帮助回忆，不替他选择或制造答案。

学生只有定性观察时，可问：“你能确认每次都成功、偶尔失败，还是只成功过一次？”整理时保留定性措辞，不换算成百分比。

## 3. 年龄分层

### 小学生

- 以1–2个功能验证为主。
- 使用可观察的“成功/失败、是否完成、用了多久”。
- 可做少量重复，不强求复杂变量分析。
- 让学生能说明“怎么测、看到了什么、所以我认为怎样”。

### 初中生

- 至少包含一个有效性/效率对比。
- 明确比较对象、主要变量和基本测试条件。
- 尽可能记录次数、耗时、准确率或错误数。
- 说明一次失败和修改后的变化。

### 高中生

- 有效性实验占主要篇幅，并补充关键性能测试。
- 明确自变量、因变量、控制变量、样本/重复次数。
- 说明数据处理、误差来源、适用边界和复测。
- 结论只覆盖实际测试条件。

年级不明时先按初中层级提出方案，并明确“年级待确认，实验复杂度可能调整”。

## 4. 有记录与无记录

### 有真实记录

1. 理解每个实验在验证什么。
2. 核对原始次数、单位、条件和对应图片。
3. 将学生口述与材料冲突之处逐项确认。
4. 再整理成“目的—方法—过程—数据—结论—修改”。

### 做过但没有表格

采访学生确认任务、次数、成功/失败、观察和修改。只使用确认过的信息。无法回忆精确次数时保留定性结果，并生成后续复测记录表。

### 尚未做实验

结合核心目标设计可执行的实验计划和空白记录表。页面写“实验计划/待开展”，不写成已完成结果。引导学生后续填写，完成后再更新演示。

课堂目标是让学生走完验证思路。允许先形成一个能支持核心装置逻辑的简单结论，但结论仍必须来自学生确认的观察或后续测试，不能凭AI编造。

## 5. 表格、图表和结论

每个实验至少包含：

```text
实验目的：验证哪个目标/功能/性能
比较对象：本项目与什么比较（如适用）
测试条件：场景、任务、距离、材料等
记录指标：时间/次数/成功失败/距离等
结果：真实表格或定性观察
结论：在该条件下说明了什么
下一步：失败、误差或需要复测的地方
```

计算规则：

- 成功率 = 成功次数 ÷ 总次数 × 100%，必须同时显示分子和分母。
- 效率提升需说明原方法和新方法的数值、单位及计算口径。
- 样本很少时优先显示原始值，不用夸张百分比。
- 图表必须与原始记录一致，坐标轴、单位、样本量可见。
- 定性结果不用伪装成精确数字。

结论句式：

```text
在【测试条件】下，本装置【完成了什么/相较什么改善了什么】；
仍会在【失败条件】出现【现象】，下一步计划【改进或复测】。
```

## 6. 常见项目指标

| 项目目标 | 效率/效果指标 | 性能指标 |
|---|---|---|
| 更快找物/定位 | 完成时间、错误位置次数 | 识别距离、响应时间、准确率 |
| 康复动作辅助 | 正确动作次数、提醒后改善 | 角度误差、重复稳定性 |
| 文化科普互动 | 正确理解/复述数、参与完成度 | 触发成功率、响应范围、运行稳定性 |
| 环境监测/控制 | 人工步骤、响应速度、控制效果 | 测量误差、工作范围、连续运行 |
| 安全提醒 | 发现风险时间、漏报/误报 | 检测距离、准确率、报警延迟 |

指标只是候选，必须根据当前项目核心目标选择，不能为了表格完整而全部使用。
